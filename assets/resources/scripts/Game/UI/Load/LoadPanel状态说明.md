# LoadPanel 状态变化说明

## 完整的加载流程和状态变化

### 1. 初始状态
- **标题**: "加载资源中"
- **进度**: "开始加载"
- **动画**: 旋转动画开始

### 2. 预加载阶段 (BundlePreloadEvent.PROGRESS)
- **标题**: "加载资源中" (保持不变)
- **进度**: "加载资源中 XX%" (XX为进度百分比)
- **动画**: 旋转动画继续

### 3. 场景资源加载阶段 (BundlePreloadEvent.SCENE_LOADED)
- **标题**: "进入场景中" (从"加载资源中"变为"进入场景中")
- **进度**: "场景资源加载完成: 场景名"
- **动画**: 旋转动画继续

### 4. 加载完成阶段 (BundlePreloadEvent.FINISH)
- **标题**: "进入场景中" (保持不变)
- **进度**: "全部加载完成！"
- **动画**: 旋转动画停止

### 5. 倒计时阶段 (showTimeNode)
- **标题**: 隐藏 (loadNode被隐藏)
- **进度**: 隐藏 (loadNode被隐藏)
- **动画**: 倒计时动画开始

## 代码实现

### 标题变化的关键代码

```typescript
// 初始状态
start() {
    this.setTitle("加载资源中");
    this.setProgress('开始加载');
}

// 预加载阶段 - 标题保持不变
processBundleProcess(data: any) {
    this.setProgress(`加载资源中 ${data.progress}%`);
    // 标题保持 "加载资源中"
}

// 场景资源加载阶段 - 标题变为"进入场景中"
onSceneLoaded(data: any) {
    this.setTitle("进入场景中");  // 关键变化点
    this.setProgress(`场景资源加载完成: ${data.sceneName}`);
}

// 加载完成阶段 - 标题保持"进入场景中"
onBundleLoadFinish() {
    this.setTitle("进入场景中");  // 确保标题正确
    this.setProgress(`全部加载完成！`);
}
```

## 用户体验

### 预加载阶段
用户看到"加载资源中"的标题，明确知道当前正在加载训练资源，进度条显示具体的加载百分比。

### 场景资源加载阶段
当标题变为"进入场景中"时，用户知道资源已经加载完成，现在正在准备进入训练场景。

### 倒计时阶段
用户看到倒计时动画，知道即将进入训练，提供了良好的过渡体验。

## 事件触发时机

1. **START**: LoadPanel显示，标题设为"加载资源中"
2. **PROGRESS**: 更新进度，标题保持"加载资源中"
3. **SCENE_LOADED**: 标题变为"进入场景中"
4. **FINISH**: 标题保持"进入场景中"，显示"全部加载完成！"
5. **showTimeNode()**: 隐藏标题和进度，显示倒计时动画

这样的设计让用户能够清楚地了解当前处于哪个加载阶段，提供了良好的用户体验。
